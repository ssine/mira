ONE-TIME SETUP

先创建管理员

Server 已连接数据库，但还没有管理员。请在 Server 主机本地执行：

cd server && npm run admin -- set-password admin

设置完成后重启 Server，再刷新此页面。密码不会写入环境变量或仓库。
